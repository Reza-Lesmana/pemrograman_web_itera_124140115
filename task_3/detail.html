Contoh desain query string

Setelah formulir dikirim, browser akan membentuk URL dengan parameter GET. Contoh berikut hanya ilustrasi, bukan data yang diproses halaman ini.

detail.html?nama=Andi+Saputra&nim=123456789&email=andi%40email.com&prodi=Teknik+Informatika&jenis_kelamin=Laki-laki&alasan=Ingin+belajar

Catatan tugas
Form pada halaman pendaftaran menggunakan method="GET". Halaman detail hanya menampilkan desain tabel dan contoh query string, tanpa menangkap data.
