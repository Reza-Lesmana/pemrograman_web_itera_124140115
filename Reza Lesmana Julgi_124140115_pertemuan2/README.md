# Student Productivity Dashboard


## Deskripsi

Aplikasi dashboard mahasiswa untuk mengelola daftar tugas kuliah.


## Fitur

- Tambah tugas
- Menghapus tugas
- Menandai tugas selesai
- Penyimpanan localStorage
- Quote motivasi API


## Implementasi ES6+

- let dan const
- Arrow Function
- Template Literal
- Class
- Async Await
- Spread Operator
- Destructuring
